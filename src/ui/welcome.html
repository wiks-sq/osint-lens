Welcome to OSINT Lens

An investigation workbench for web pages: identifiers, infrastructure, technologies, exposed data and phishing triage, with local AI and any MCP tools you connect.

1. Pin it and open the side panel

  1. Click the puzzle-piece icon in Chrome's toolbar and pin OSINT Lens.
  2. On any web page, click the icon (or press Alt+Shift+O). The side panel opens and stays open while you browse.
  3. Press Scan page (Alt+Shift+S).

Clicking the toolbar icon gives the extension one-time access to that tab. To scan any tab from the side panel without clicking the icon each time, allow access to all sites in Settings → Privacy & data.

2. Investigate

  • Indicators: emails, phones, social profiles, wallets, tracking and ad IDs, verification tokens, IPs, coordinates… each with pivot links.
  • Online lookups: DNS, registration (RDAP), hosting/ASN, open ports, subdomains from certificate logs, archive history and earlier public scans.
  • Files: GPS, camera and author metadata from the page's photos and documents.
  • Evidence: screenshots and full-page MHTML archives with SHA-256 hashes.
  • History: every scan is kept locally; shared identifiers link sites across your investigations automatically.
  • Right-click any selected text, link or image → Investigate.

3. Add AI (optional)

Install Ollama, pull a model that supports tool calling and open Settings → AI:

ollama pull qwen3:8b

Everything stays on your computer with Ollama. OpenAI-compatible servers (LM Studio, llama.cpp, vLLM…) and Anthropic are also supported.

4. Connect MCP servers (optional)

Any Model Context Protocol server can be added in Settings → MCP servers: remote servers by URL, local stdio servers through the bundled bridge:

node tools/mcp-bridge.mjs -- npx -y @modelcontextprotocol/server-everything

Run tools yourself from the MCP tab, save them as recipes, or let the AI call them (with your approval).

Use it responsibly

OSINT Lens reads what a page already shows you and queries public sources. Investigate only what you're entitled to, respect the terms of the services you query, and treat heuristic results as leads to verify. See docs/PRIVACY.md for exactly what is sent where.
